# Cinejoy TV for Windows

Windows desktop WebView2 wrapper for https://cinejoy.pk/.

Features:
- Fullscreen desktop interface
- Cinejoy-only top-level navigation
- Blocks common ad/redirect hosts
- Blocks intent:, market:, tel:, mailto:, WhatsApp, Telegram and similar schemes
- Blocks popup/new-window requests
- Allows external media/resources to load as subresources
- Client-side popup/link guard
- F5 reload and Alt+Left back navigation

Requirements:
- Windows 10/11
- Microsoft Edge WebView2 Runtime

The project uses Microsoft.Web.WebView2 1.0.4191.47.
